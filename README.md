# Home Petkit

A collection of custom pets.

## Install

### Codex

Download a pet archive from [Releases](https://github.com/NCUnix/home-petkit/releases) and extract it into your Codex pets directory:

```sh
mkdir -p "${CODEX_HOME:-$HOME/.codex}/pets"
tar -xzf codex-little-home.tar.gz -C "${CODEX_HOME:-$HOME/.codex}/pets"
```
